# KeaBuilder AI Engine

AI-powered SaaS assistant for funnels, lead capture, automation and content generation.

## Features

- Lead Scoring (Hot/Warm/Cold)
- AI Replies
- Funnel Copy Generator
- Workflow Automation
- Similarity Search
- Provider Routing
- Reliability Dashboard
